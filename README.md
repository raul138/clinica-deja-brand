# Portal da Marca Clínica Déjà

Biblioteca pública da identidade visual e arquivos da marca. Site estático, sem dependências e sem coleta de dados.

## Publicação
No GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Atualização
Edite index.html, styles.css e app.js; substitua os arquivos mantendo os nomes e registre um commit. Atualize versão e conteúdo de instrucoes-ia.md/tokens.json quando as regras mudarem. GitHub Pages publicará a atualização.

## Uso por IA
Forneça o link de instrucoes-ia.md ou llms.txt e dos arquivos de que a ferramenta precisa. No Lovable, adicione as regras a Project settings → Knowledge. No Claude, adicione-as ao conhecimento de um projeto. Um link público não garante ingestão automática por qualquer ferramenta.

## Arquivos
Manual PDF, guia editável, tokens de design, escalas HEX, logos PNG, fontes originais e mosaicos com prompts. Fotografias geradas por IA; tema Ambiente removido.

## Direitos
A identidade e os logos pertencem à Clínica Déjà; acesso público não transfere a marca. As fontes são distribuídas sob SIL Open Font License (ver OFL-*.txt).
